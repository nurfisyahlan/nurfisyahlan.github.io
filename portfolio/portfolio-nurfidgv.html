Portfolio Details

Website yang terhubung langsung dengan API OMDb untuk mengambil data film dan sinetron yang ada dari seluruh dunia

Nurfi DGV - Movie Databases

Website ini dirancang untuk menampilkan data film secara dinamis dengan memanfaatkan API dari OMDb (Open Movie Database). Pengguna dapat mencari film dengan mengetikkan judul pada kolom pencarian yang tersedia. Setelah tombol “Cari” ditekan atau pengguna menekan tombol Enter, sistem akan mengirim permintaan (request) ke API OMDb menggunakan JavaScript untuk mengambil data film yang relevan berdasarkan kata kunci yang dimasukkan.

Setelah mendapatkan respon dari API, data yang diterima dalam bentuk JSON akan diproses dan ditampilkan secara visual pada halaman web. Setiap film akan ditampilkan dalam bentuk kartu (card) yang berisi gambar poster film tersebut. Jika film yang dicari terdiri dari beberapa seri (misalnya seperti film Cars), maka seluruh seri yang sesuai akan ditampilkan secara berdampingan dalam satu tampilan.

Setiap kartu film memiliki fungsi interaktif berupa tombol atau area klik yang dapat dibuka sebagai popup atau modal. Ketika pengguna mengklik poster atau tombol detail dari film tertentu, sistem akan mengambil data lengkap film tersebut (seperti tahun rilis, genre, sutradara, pemeran, dan plot) dari OMDb API berdasarkan ID film-nya, lalu menampilkannya di dalam popup secara responsif. Hal ini memberikan pengalaman interaktif yang lebih kaya tanpa harus berpindah halaman.

Website ini dibuat dengan HTML, CSS, dan JavaScript murni tanpa framework, sehingga cocok untuk latihan dasar pemrograman web. Gaya tampilan dibuat sederhana namun menarik, dan pencarian dilakukan secara real-time agar pengguna dapat langsung melihat hasil pencarian sesuai keinginan mereka. Dengan demikian, website ini tidak hanya berfungsi sebagai penampil film, tetapi juga sebagai media eksplorasi belajar dalam menghubungkan frontend web dengan data dari layanan API eksternal.
